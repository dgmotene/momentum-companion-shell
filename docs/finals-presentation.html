Secure Architecture02

Four trust zones. The model carries no authority.

ZONE 1

Host Portal

Authenticates the user and signs a short-lived RS256 identity token.

Next.js · JWKS
ZONE 2

Companion

Isolated iframe. Receives identity through origin-pinned postMessage.

Next.js · no secrets
ZONE 3

Backend

Verifies JWT, checks role, retrieves evidence, runs actions and audits.

Node · Postgres · pgvector
ZONE 4

AI Gateway

Stateless chat and embeddings. Never sees or decides user permissions.

Haiku · Titan v2
User JWT: Host → iframe → backend. Proves who the person is.
Gateway key: Backend → gateway only. Proves which app is calling.

Model advises. Code decides.
